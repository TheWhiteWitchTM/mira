---
title: Why the card is Next.js
description: A consultant site has to be fast, cheap to host, and easy to change. Static Next.js on GitHub Pages is that. PHP was a server I did not want to keep.
date: 2026-10-26
tags: [nextjs]
---

A consultant site is a card. It has to load on a phone, survive a week of no deploys, and cost nothing while I am in a C++ codebase.

PHP on a VPS can do that. I have done that. The bill is the updates, the plugins, and the night the theme fights the cache. WordPress is a CMS. I needed a folder of pages.

Next.js with `output: "export"` is a compiler for that folder. TypeScript checks the shapes. Tailwind keeps the CSS in the markup. MDX is the blog. GitHub Pages is the host. The Google tag is the same one as the witch.

The trade: no server. No form endpoint, no preview that is not a file. For a card, that is the feature. The tools on this site run in the browser on purpose. Your picture never leaves your machine.

If a client needs a native program, that is a C++ job, or an API they already have. The card stays static.
