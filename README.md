The pages are a static Next.js export. GitHub Pages serves them at `/mira/`.

## Develop

```bash
npm install
npm run dev
```

The dev server is at `http://localhost:3000`.

```bash
npm run build
```

`npm run build` writes the static site to `out/` with the `/mira` base path. It also refreshes `public/feed.xml`.
