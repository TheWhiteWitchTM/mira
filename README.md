## Develop

```bash
npm install
npm run dev
```

The dev server is at `http://localhost:3000`.

```bash
npm run build
```

`npm run build` writes `out/` at the domain root, refreshes `public/feed.xml`, writes `.nojekyll`, and copies into `TheWhiteWitchTM.github.io/mira/` when that repo sits next to this one.
