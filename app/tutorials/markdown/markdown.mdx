## Headings

One `#` per level, and do not skip a level. A screen reader walks them in order.

```markdown
## Section
### Subsection
```

## Links and images

```markdown
[The card](https://thewhitewitchtm.github.io/)

![Mira](/banner.jpg)
```

Write the address out when the words and the URL should both be visible. A bare URL is easy to mistype inside a sentence, and a reader on a phone cannot hover it.

## Code

Inline code uses single backticks: `const site = "mira"`.

A fence names the language on the first line. These four are the ones I reach for.

```ts
export function withBase(path: string): string {
  const normalized = path.startsWith("/") ? path : `/${path}`
  return `${normalized}`
}
```

## What this site does not render

`==highlight==` is a GitHub extra. Leave it out.

GitHub callouts (`> [!NOTE]`) stay as a normal quote here. If the note matters, write it as a sentence.

## MDX

MDX is Markdown plus a component. Keep the component for something the words cannot do. A button is enough of an example.

```mdx
import { Button } from "@/components/ui/button"

<Button variant="outline" size="sm">A real button</Button>
```

<Button variant="outline" size="sm">A real button</Button>

The button is the component. The fence above it is the source, highlighted as `mdx`.
